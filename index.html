Get started

Deploy in four steps.

Before you begin, install Terraform and AWS CLI, and configure AWS credentials with permission to create the project resources.

Clone the project

Get the Terraform configuration and deployment script from GitHub.

Initialize Terraform

Run terraform init to install the required provider.

Review and apply

Plan the changes, then apply to create the AWS resources.

Visit your server

Open the public IP from Terraform output in your browser.

Ready to build it yourself?

Read the project instructions, review the Terraform files, and deploy in your AWS account.
